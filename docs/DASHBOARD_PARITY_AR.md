# تكافؤ اللوحة الجديدة مع لوحة Valex القديمة

هذا الملف يسجل قرار نقل كل وظيفة أو Widget من القالب القديم إلى لوحة WeCare.

| العنصر القديم | الحالة في WeCare | القرار |
|---|---|---|
| Sales / Orders / Customers | لا يخص النظام الصحي | لا ينقل |
| Revenue / Profit / Earnings | لا توجد أعمدة تكلفة موثوقة في قاعدة XAMPP الحالية | مؤجل حتى إضافة نموذج مالي صحيح |
| Calendar | تقويم شهري حقيقي للمواعيد في لوحتي الإدارة والطبيب | منفذ |
| Latest Tasks | مركز مهام مشتق من المواعيد والأسئلة ونقص البيانات | منفذ |
| Notifications | تنبيهات تشغيلية ديناميكية داخل مركز المهام دون جدول جديد | منفذ جزئيًا؛ حالة مقروء/غير مقروء تحتاج جدولًا لاحقًا |
| Overall Rating | صفحة إدارية بوضع توافق، لكن حقول التقييم غير موجودة في مخطط `doctors` الحالي | تعرض الأطباء دون خطأ، وتُفعّل مؤشرات التقييم تلقائيًا عند توفر الحقول |
| Recent Reviews | قاعدة البيانات تحفظ تقييمًا مجمعًا فقط ولا تحفظ مراجعات مستقلة | مؤجل |
| Recent Customers | المرضى المضافون حديثًا | منفذ |
| Recent Orders | مواعيد اليوم والقادمة | البديل منفذ |
| Activity Chart | نشاط المواعيد لآخر سبعة أيام | منفذ |
| Map USA | خريطة انتشار الأمراض في سورية بنوعيها | البديل منفذ |
| Quick buttons | إجراءات حسب الدور للمرضى والمواعيد والأطباء والتقارير والملفات والأسئلة والتحليل والإعلانات | منفذ |
| Draggable cards | لا توجد تفضيلات Dashboard مخزنة | تحسين غير أساسي مؤجل |
| Chat / Mail | لا يوجد Backend للمحادثات أو البريد الداخلي | لا ينقل كواجهة وهمية |
| Video icon | لا يوجد WebRTC أو مزود مكالمات | مؤجل كمشروع مستقل |
| Invoice / Pricing / Cart / Products | تجارة إلكترونية تجريبية | لا ينقل |
| Browser Usage / Bounce Rate / Real-time users | لا يوجد نظام Analytics للزوار | غير مطلوب تشغيليًا حاليًا |
| To-do مستقل | استبدل بمهام تشغيلية حقيقية | منفذ |
| Data tables / alerts / badges / modals | مستخدمة كمكونات ضمن الصفحات الحقيقية | البديل موجود |

## العمليات القديمة ذات البدائل الحالية

- المستخدمون والصلاحيات: إدارة النظام.
- الأقسام والأطباء والمرضى: إدارة الرعاية.
- الحجوزات: المواعيد مع تأكيد وإلغاء وفلاتر وتقويم.
- عائدات الزيارات: «زياراتي»؛ الإيراد متوقف حتى توفر عمود تكلفة فعلي.
- التقارير: تقارير تشغيلية وتصدير CSV.
- الإعلانات: إدارة الإعلانات للمدير.
- أسئلة المرضى: جميع الأسئلة، أسئلة العيادة، والأسئلة المعلقة.
- `database`: استبدلت بالملفات الطبية.
- الخرائط: استبدلت بتحليل انتشار الأمراض في سورية.

## قيود قاعدة البيانات المكتشفة

- `cln_x_visits` لا يحتوي `price`، لذلك لا يمكن حساب إيراد حقيقي.
- `doctors` لا يحتوي `total_rate` و`revisions_num` في القاعدة الحالية.
- `wallet` لا يحتوي `patient_id` في القاعدة الحالية، لذلك لا يمكن إسناد الحركات إلى المرضى بصورة موثوقة.

لا يجوز إظهار أرقام مالية أو تقييمات وهمية لتعويض هذه الحقول.
